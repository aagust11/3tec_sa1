Experimenta

Investiga els contactes

Amb el muntatge recíproc proporcionat pel professorat o un model ja construït, fotografia la posició inicial i numera les peces. Treballa amb peces lleugeres damunt la taula.

  1. Assenyala sobre la fotografia els punts de contacte.
  2. Explica què sosté cada peça i sobre quines altres recolza.
  3. Preveu què passaria si disminuís el fregament. Contrasta la hipòtesi només en un model petit i estable, sense càrrega afegida.
  4. Compara aquest sistema amb una unió cargolada i amb un arc de dovelles.

Conclusió: distingeix les observacions directes de les prediccions. No dedueixis la seguretat d’un pont real a partir d’aquest model.
