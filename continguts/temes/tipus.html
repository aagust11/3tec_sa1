Una estructura és un conjunt d’elements organitzats per suportar càrregues, mantenir una forma i protegir o sostenir alguna cosa.

1. Naturals i artificials

L’esquelet, el tronc d’un arbre o una closca són estructures naturals. Un pont, una bastida o una llauna són artificials: les hem dissenyat les persones.

2. Classificar per la forma de construir

Massisses

Molts materials i una base ampla. Les càrregues es transmeten principalment per compressió.

Exemple: una presa de gravetat.

Entramades

Pilars i bigues formen un esquelet que sosté els pisos i la coberta.

Exemple: l’estructura d’un edifici.

Triangulades

Barres unides en triangles donen rigidesa amb poc material.

Exemple: una grua de gelosia.

Laminars

Làmines o superfícies primes formen una carcassa resistent.

Exemple: una llauna de beguda.

Penjades

Cables o tirants suporten una part important de les càrregues treballant a tracció.

Exemple: una passarel·la penjant.

Pneumàtiques

L’aire a pressió manté tensa una membrana flexible.

Exemple: una estructura inflable.

Amb cúpules

Una coberta corbada reparteix les càrregues cap al perímetre.

Exemple: una cúpula de maó.

Geodèsiques

Una xarxa de triangles aproxima una superfície esfèrica. Són un cas de triangulació.

Exemple: un hivernacle geodèsic.
Una construcció pot combinar sistemes

Un edifici pot tenir pilars i bigues, una coberta triangulada i peces laminars. Justifica la classificació amb els elements que observes.

Una tenda amb pals és sempre pneumàtica?

No. Només ho és si elements inflats o aire a pressió mantenen la forma estructural. Una lona sobre pals no és, per aquest fet, pneumàtica.

EXEMPLE RAONAT

Una bicicleta combina solucions

El quadre d’una bicicleta convencional conté disposicions triangulades; els radis de les rodes treballen tibats; altres peces poden formar carcasses. Classificar tot l’objecte amb una sola etiqueta pot ocultar aquesta combinació.

Ara et toca:

Tria una peça concreta, descriu la geometria i justifica quin sistema hi reconeixes.
