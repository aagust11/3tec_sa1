# Exercicis creats pel professorat

Obre `administracio-exercicis.html`. Crea o selecciona un exercici, revisa la previsualització i descarrega el JSON. Puja'l aquí amb el mateix nom (`S1E1.json`) per actualitzar-lo. No cal editar cap índex: GitHub Pages genera el llistat de tots els JSON d'aquesta carpeta en publicar.

Les imatges PNG/JPEG/WebP es redimensionen i s'incorporen dins del JSON. No cal cap carpeta d'imatges. L'amplada es configura com a percentatge del contingut i s'adapta a la pantalla.

Identificadors únics. Per eliminar un exercici, elimina el JSON a GitHub. Per canviar-ne l'identificador, puja el fitxer nou i elimina l'antic. Espera que acabi la publicació de Pages i recarrega el llistat.

L'editor demana una contrasenya d'accés bàsica al navegador i només genera fitxers locals. Aquesta barrera no és una autenticació de servidor; els fitxers del repositori són públics. No publica ni modifica GitHub. Les solucions publicades són accessibles a l'alumnat.
